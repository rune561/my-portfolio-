MY PORTFOLIO

ABOUT THE PROJECT
-----------------
This is my personal portfolio website. It presents my background, skills,
projects, education, achievements and contact details in one responsive
page. It was built for the assignment "Personal Portfolio Website Design
and Development".
 
 
SECTIONS
--------
1. Home       - name, headline, short introduction and profile image
2. About Me   - who I am, my interests and career goals
3. Skills     - technical skills, tools and other skills
4. Projects   - three projects with descriptions, technologies
                used and links to the source code or live site
5. Education  - qualifications, certifications and achievements
6. Contact    - email, GitHub link
 
FEATURES
--------
- Responsive layout for desktop, tablet and mobile
- Dark and light theme toggle 
- Mobile hamburger menu
- Smooth-scroll navigation with the current section highlighted
- Project filter buttons
- Animated skill bars
- Contact form with input validation (opens the visitor's email app
  with the message filled in)
- Back-to-top button
- Keyboard-friendly focus styles and reduced-motion support
 
 
TECHNOLOGIES USED
-----------------
- HTML5
- CSS3 (custom properties, flexbox, grid, media queries)
- JavaScript (vanilla, no frameworks or libraries)
- Google Fonts (Bricolage Grotesque and Figtree)
- Hosting: GitHub Pages
