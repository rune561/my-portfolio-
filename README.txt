SHERAB PEM - PERSONAL PORTFOLIO

Files:
- index.html: Website content
- style.css: Layout, dark blue colour theme, and dark-mode styles
- script.js: Mobile menu, dark/light mode button, and automatic year

HOW TO OPEN:
1. Extract this ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension.

DARK MODE:
Use the "Dark Mode" button in the top navigation. It switches between light and dark themes and remembers the selected theme in your browser.

BEFORE SUBMISSION:
- Replace "Add your email address" with your real email.
- Add your GitHub profile link.
- Check that the listed projects accurately describe your work.

PROFILE PHOTO:
- profile-photo.jpg appears in the Home section.
- Keep it in the same folder as index.html, style.css, and script.js.

CERTIFICATES:
A Certificates section has been added to the website. It includes five PDF certificates.
Use the View Certificate link to open a PDF in the browser, or Download PDF to save it.
Keep the certificates folder beside index.html when uploading/deploying the website.

DESIGN UPDATE:
The visual design now includes animated profile photo, floating background shapes, scroll reveal effects, hover animations, and a reading progress bar. Existing portfolio text and certificates are retained.

PHOTO ANIMATION:
The profile photo now has a spinning gradient border, pulsing glow, floating sparkle dots, a zoom-in entrance, and a 3D tilt that follows your mouse. Animations are disabled automatically for visitors who prefer reduced motion.
